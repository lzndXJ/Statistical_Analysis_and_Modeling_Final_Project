# 提交与答辩清单

## 项目材料

| 材料 | 内容与负责人 |
| --- | --- |
| **项目报告** | Word 或 PDF，由组长撰写和定稿。包含 GitHub 仓库链接、研究背景和目标、数据收集与处理、建模与评估、尝试过的模型调整及其效果、结果解读与应用、团队协作记录、总结与改进方向、AI 工具使用说明 |
| **答辩 PPT** | C 独立制作，覆盖研究问题、数据、模型表现与优化效果、主要发现及原型演示 |
| **项目视频** | A 独立录制与剪辑，时长不超过 5 分钟 |
| **完整数据和源码** | 数据放入 [data/](../data/)，源码放入 [code/](../code/)。B 提供原型源码及运行说明 |
| **提交 ZIP** | A 汇总并打包报告、PPT、项目视频、完整数据和源码。组内指定一名同学在答辩前通过 Canvas 提交 |

公开 GitHub 仓库须包含项目数据、源码、项目说明和项目视频。检查数据来源注明情况、项目数据文件大小、运行步骤和最终材料能否打开。

## 课堂答辩

第 16 周上课时间进行课堂答辩。全组四人到场，由 C 主讲 **10 分钟**并演示原型，随后 **5 分钟问答**由相关负责人回答。排练时核对展示的图表、模型数字和报告是否一致。
