# 项目约定

## 研究问题

**在前一天做准备时，口岸客流管理人员如何判断哪些口岸、哪些出入境方向需要优先关注？** 项目用预计人次和高客流概率辅助确定准备顺序。日客流数据能支持按天比较，估计具体排队时长或逐小时调配人手需要更细的观测。

## 已确认事项

| 事项 | 约定 |
| --- | --- |
| 选择口岸 | 罗湖、落马洲支线、深圳湾 |
| 分析单位 | 一个观测日期、一个口岸、一个方向。入境指进入香港，出境指离开香港 |
| 数据日期 | 2024-01-01 至 2026-10-31，含首尾两天。实际覆盖由数据核验确认 |
| 预测时点 | 香港时间前一天 18:00 给出次日预测。数据核验前，历史客流暂用目标日前两天及更早的已发布记录。例如预测 10 月 4 日客流，暂用 10 月 2 日及以前的数据 |
| 日历信息 | 分别标记香港公众假期、内地放假和内地调休补班。涵盖工作日、周末和节假日，单独检查周末和节假日的模型表现 |
| 回归任务 | 估计三个口岸各方向的次日客流人次，每天共六项结果 |
| 分类任务 | 估计同一口岸、同一方向次日属于高客流的概率 |
| 高客流定义 | 以训练期内每个口岸和方向的客流第 90 百分位作为人数阈值。当天人次达到该组阈值即记为高客流 |
| 预警原则 | 优先减少漏报，同时观察误报。用验证结果决定发出预警的概率门槛 |

人数阈值用于标记哪些历史日期实际属于高客流，概率门槛用于决定模型是否发出提醒。

## 待讨论事项

- 核验数据并学习相关课程内容后，再确定具体模型、基准方法、时间切分和评价指标。
- 分析结果完成后，由组长和原型、汇报负责人定原型页面、交互方式和现场演示案例。

数据采用[官方来源和清洗口径](../data/README.md)。工作顺序见[分工与协作](分工与协作.md)。
