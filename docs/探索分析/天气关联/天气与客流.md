# 天气与三个陆路口岸客流的关联

以复核后的六组逐日客流为基础，分别比较天气实况、恶劣天气警告和历史天气预报。样本覆盖 **2024-01-01 至 2026-10-31**，共 1,035 个目标日。三口岸合计为六组通关人次的日总和。 [客流探索分析](../客流探索分析.md) · [客流分析输入](../../../data/traffic_calendar.csv)

## 三类天气数据

| 数据 | 本次使用的字段 | 日期覆盖 |
| --- | --- | --- |
| 实况 | 天文台总部的当天总雨量和日平均气温。微量降雨保留标记，数值栏以 0 毫米计。 | 1,035 天。 [日雨量 CSV](https://data.weather.gov.hk/weatherAPI/cis/csvfile/HKO/ALL/daily_HKO_RF_ALL.csv) · [日平均气温资源](https://data.gov.hk/en-data/dataset/hk-hko-rss-daily-temperature-info-hko/resource/e8efc5d3-9a6f-48ca-bded-7bb0f5ca46ce) |

显著降雨概率指全港普遍日雨量达到 10 毫米或以上的预报概率。本试验对照「中高或高」和其余等级。当天实况、当天最高警告用于回看历史。前一日 18:00 的警告和在该时点可见的预报对应项目的预测时点。由于归档间隔，试验选中的预报可能早于当时的最新公告。 [显著降雨概率定义](https://www.hko.gov.hk/en/education/weather/rain/00568-Q-%26-A-for-Probability-of-Significant-Rain.html) · [逐日天气表](../../../data/weather_daily.csv) · [数据来源与校验值](../../../data/weather_sources.json)

## 计算方法

对六组和三口岸合计分别计算。每次比较一个天气因素，以日客流的对数为因变量。先做不控制其他条件的比较，再把年月、星期几、香港公众假期、内地放假和补班放进同一个回归。表里的百分比由回归系数 $\beta$ 换算为 $100(\exp(\beta)-1)$。比如 −11.7% 表示在这些日期条件相同的比较口径下，该类日的估计客流水平约低 11.7%。最后去掉六组共同最低值 **2025-09-24** 再算一次，查看一个极端日对结果的影响。

## 结果

下表为三口岸合计。「条件日」按日期计数。气温和连续雨量项比较的是每增加指定单位的差异。六组各自的估计和未经控制的结果见 CSV。

| 天气因素 | 样本天数 | 条件日 | 考虑日历和月份后的差异 | 去掉 2025-09-24 后 |
| --- | ---: | ---: | ---: | ---: |
| 当天实测雨量每多 10 毫米 | 1,035 | — | −2.8% | −2.0% |
| 当天实测雨量至少 25 毫米 | 1,035 | 93 | −12.8% | −10.0% |
| 当天实测平均气温每高 5 ℃ | 1,035 | — | +5.3% | +4.3% |
| 当天曾有八号或以上台风信号 | 1,035 | 11 | −54.1% | −43.8% |
| 当天曾有暴雨警告 | 1,035 | 115 | −12.3% | −9.9% |
| 前一天 18:00 有三号或以上台风信号 | 1,035 | 19 | −34.2% | −25.2% |
| 前一天 18:00 有八号或以上台风信号 | 1,035 | 3 | −62.7% | −6.5% |
| 前一天 18:00 有暴雨警告 | 1,035 | 14 | −2.1% | −2.7% |
| 次日显著降雨概率为中高或高 | 1,034 | 184 | −11.7% | −10.1% |
| 次日预报最高气温每高 5 ℃ | 1,034 | — | +5.8% | +4.6% |

- **实况。** 日雨量至少 25 毫米的日子，六组客流估计均较低，差幅 **11.3%–15.1%**。删掉桦加沙当天后，六组仍低 **8.9%–12.0%**。
- **警告。** 前一日 18:00 有三号或以上台风信号时，六组均有较低客流。八号或以上只有 3 天，删掉一个极端日后总体估计大幅缩小。前一日的暴雨警告只有 14 天，六组方向并不完全一致。
- **预报。** 显著降雨概率为中高或高时，六组估计均低 **10.5%–13.2%**。删掉桦加沙当天后，六组仍低 **9.2%–11.0%**。预报气温较高时的正向关系也出现在六组，但气温和降雨可以共同变化，各天气因素在这里是分别估计的。

这些是全期历史关联。**次日显著降雨概率**和**前一天 18:00 的台风信号**已作为 `forecast_psr` 和 `tc_signal_at_cutoff` 按目标日加入分析主表。主表保存五档预报及原始信号编号，供后续验证期比较有无天气特征的客流误差和预警漏报、误报。 [字段与缺失说明](../../../data/README.md#天气数据issue-10) · [完整分组结果](weather_associations.csv)

## 复算

在仓库根目录使用 Python 3.10+、pandas 和 NumPy。离线分析直接使用已整理的逐日天气表。

```powershell
python code/explore_weather_traffic.py
```

从官方源重建天气表时使用 lxml。原始文件缓存于 `tmp/issue-10-weather-source/`，结果写入 `data/`。本次使用的 72 个源文件及其 SHA-256 已列在来源清单中。重建后运行合表脚本同步主表和核验 JSON。

```powershell
python code/build_weather_eda_inputs.py --download
python code/merge_traffic_calendar.py
python code/explore_weather_traffic.py
```
