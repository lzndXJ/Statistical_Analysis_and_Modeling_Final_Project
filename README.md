# 香港主要陆路口岸次日客流预测与高客流预警

系统分析与建模课程期末项目。我们用香港入境事务处的逐日客流，帮助口岸管理人员提前判断哪些口岸、哪些出入境方向需要优先准备人手和现场引导。香港特区政府在 2026 年国庆黄金周前已针对这些口岸开展客流估算和现场准备。 [香港特区政府的黄金周客流安排](https://www.info.gov.hk/gia/general/202609/28/P2026092800600p.htm)

- **对象**为罗湖、落马洲支线和深圳湾，入境、出境分别分析。
- **数据范围**为 2024 年 1 月 1 日至 2026 年 10 月 31 日，纳入香港公众假期、内地放假和调休补班。
- **建模任务**为估计次日客流人次和高客流概率。覆盖各类日期，单独检查周末和节假日的表现。
